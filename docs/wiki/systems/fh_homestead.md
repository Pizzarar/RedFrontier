# Homestead

Homesteads are fixed plots you claim. Four plots exist in the Heartlands. See [Regions](../regions.md).

## Claiming
- Stand inside a plot and use `/fh_claim`. Plots are 25 m in radius.
- One plot per character.
- Use `/fh_unclaim` to release your plot. Chest contents stay in the chest when you unclaim. See [Controls](../controls.md).

## Your chest
Every plot has one owner-only chest. Walk up and press `E` (unverified). It accepts pocket, bulky and cargo items, so it is where big loot ends up. See [Items](../items.md).

## Building
The plot data lists build slots: cabin, fence, workbench, campfire, tanning rack, trophy wall and extra chests. **The build flow is not built yet**, so you can't build them in game. See also [Crafting](crafting.md).

Plot positions are approximate and not yet checked in game.
